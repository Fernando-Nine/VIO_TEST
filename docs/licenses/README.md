# Licenças de terceiros

Os arquivos desta pasta preservam as licenças das fontes tipográficas e das
bibliotecas diretamente utilizadas no cliente. As demais dependências instaladas
retêm suas licenças em seus pacotes; consulte o lockfile para as versões exatas.
O código específico do VIO usa AGPL-3.0-only.

Fontes atuais: Bricolage Grotesque e IBM Plex Mono, servidas
localmente com licença OFL. As licenças Instrument Serif (2.1–2.2) e Manrope permanecem como registro histórico das tipografias utilizadas nas versões anteriores.
