# Brandbook do VIO

Identidade oficial. Aqui entra **só o que o usuário já decidiu**: sem propostas, sem opções, sem
"sugerido". Cada item cita de onde veio a decisão (decisão nº, data, prancha).

- O que ainda está em aberto: [`../escolhas/`](../escolhas/README.md). Quando o usuário decide, o
  resultado entra aqui e a escolha é fechada.
- Como produzir (guias): [`../guias/`](../guias/). Ordem do trabalho: [`../guias/plano.md`](../guias/plano.md).
- Arquivos prontos: [`../brandkit/`](../brandkit/).

| Capítulo                              | Arquivo                          |
| ------------------------------------- | -------------------------------- |
| Marca: logo, nome, assinatura, ícones | [marca.md](marca.md)             |
| Tema, fontes, ícones                  | [fundamentos.md](fundamentos.md) |
| O Ponto e o avatar                    | [ponto.md](ponto.md)             |
| Voz e tom                             | [voz.md](voz.md)                 |
| Imagem                                | [imagem.md](imagem.md)           |

O que depende do estilo final (raio, sombra, densidade, contraste, paleta final) entra na fase 3 do
plano, depois da exploração de estilo.
