# Padrão dos widgets — spec (escolha A, com o selo de permissão da B)

Pranchas "5A", "5B" e "5 · Onde cada padrão se aplica" (https://claude.ai/artifact/819UwyvwKn6c5WCU1X5Hv8). Base na skill
`vio-design-system`.

## Cabeçalho

Ícone + título (editável no lugar) + **selo de quem controla** (da B), antes do X:

- **Todos** (ícone de pessoas) — convidados podem controlar;
- **Admins** (escudo) — só criador e administradores;
- **Só você** (pessoa, borda tracejada) — widget pessoal.
  Tocar/hover no selo mostra quem controla ("Nine e Lia controlam este widget.").
  Quem não pode controlar vê o estado (ex.: "Em andamento"), **sem botão morto**.

## Menu do botão direito (A)

Mesma ordem em todos: Trazer para o foco → Renomear → Cor e paleta → Quem pode
controlar → separador → Remover deste layout → Encerrar para todos (vermelho; só sala e
só para quem pode). Widget pessoal não tem "Quem pode controlar" nem "Encerrar para
todos". No celular, toque longo abre o mesmo menu como folha.

## Cor e paleta (A)

O seletor da roleta: 12 cores, barra de matiz, HEX e paletas (Índigo, Pôr do sol,
Floresta, Doce, Aleatória). Widget com uma cor só mostra cores e HEX.

## Onde se aplica

Segue a tabela da prancha "5 · Onde cada padrão se aplica" (cor: Cronômetro, Votação/
pizza, Sorteador, Personalizado; permissão: widgets da sala com controle/edição; menu:
todos, com itens próprios quando houver).

## Modelo

Não existe compartilhar widget: pessoal ou da sala, escolhido na criação ("Para mim" /
"Para a sala").
