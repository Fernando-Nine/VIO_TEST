# Escolhas em aberto

Cada arquivo desta pasta é **uma escolha pendente do usuário**, com o link da prancha e as opções.
Nada daqui vale como identidade oficial.

## Fluxo

1. A escolha nasce aqui, num arquivo próprio, com opções, origem e a fase do
   [plano](../guias/plano.md) em que se decide.
2. Quando o usuário decide, o resultado entra no [brandbook](../brandbook/README.md), citando
   decisão, data e prancha.
3. O arquivo é movido para [`fechadas/`](fechadas/) com a data no nome (`AAAA-MM-DD-<escolha>.md`)
   e a decisão anotada no fim.
