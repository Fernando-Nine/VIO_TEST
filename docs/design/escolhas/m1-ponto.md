# Cor do ponto da M1

A M1 (ícone para uso sobre azul) está decidida
([brandbook](../brandbook/marca.md#ícones-do-app)); a cor do ponto, não. Os dois quadros da prancha
"VIO · Marca" (https://claude.ai/artifact/CQ7zbg9248JmEqZFeHAAoo, 29 out 2026) divergem:

| Opção     | Origem                                                          | Arquivo                                    |
| --------- | --------------------------------------------------------------- | ------------------------------------------ |
| `#A6A9FF` | quadro "Escolhida · Logo VIO (N3 arredondada) + ícones M4 e M1" | [m1-ponto-a6a9ff.svg](m1-ponto-a6a9ff.svg) |
| `#F3F3FB` | quadro "Escolhidas · Ícones M4 (principal) e M1"                | [m1-ponto-f3f3fb.svg](m1-ponto-f3f3fb.svg) |
| Preto     | sugestão do usuário (resposta à P8, 9 nov 2026)                 | ainda sem arquivo                          |

Contrastes sobre o azul `#2727F5`: `#A6A9FF` 3,61:1 (contra o "v" branco, 2,16:1); `#F3F3FB` 7,06:1
(contra o "v", 1,10:1); preto cerca de 2,7:1, abaixo de 3:1 para elemento gráfico.

Em 9 nov 2026 o usuário não decidiu (P8): acha o ponto diferente interessante, não sabe se gosta da
cor e sugeriu testar preto para dar contraste. **Em aberto.** Espera comparação visual das três
candidatas, só se o usuário pedir.

Decisão: confirmar com o usuário. O SVG escolhido vai para `../brandkit/icone-m1-azul.svg`.
