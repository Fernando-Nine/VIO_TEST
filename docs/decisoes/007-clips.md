# 007 — Clips

Data: 2026-10 (#208)

## Contexto

Quem assiste junto quer guardar momentos.

## Decisão

Clips gravados no aparelho, até 3 minutos, com as vozes de todos, edição rápida em
milissegundos e marca d'água. Nada é gravado no servidor.

## Motivo

Guarda o momento sem custo de servidor nem dados de terceiros fora do aparelho.

Não rediscutir sem o usuário.
