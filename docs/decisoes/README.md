# Decisões (ADRs)

Cada decisão do usuário que vale para todos vira um arquivo `NNN-titulo.md` aqui. O índice fica
na seção Decisões do `docs/ESTADO.md`. Decisão nova: próximo número, e uma linha no índice.
Decisão que muda outra: arquivo novo que cita a antiga; a antiga ganha "Substituída por NNN".

## Formato

```
# NNN — Título

Data: AAAA-MM-DD (issues, se houver)

## Contexto
O problema, em 2–4 frases.

## Decisão
O que foi decidido.

## Motivo
Por que esta e não outra.

Não rediscutir sem o usuário.
```
