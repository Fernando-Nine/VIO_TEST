# 009 — Contas, banco de dados e gravação no servidor adiados

Data: 2026-10

## Contexto

Contas e banco trariam histórico e perfis, mas também custo, LGPD e manutenção.

## Decisão

Contas, banco de dados e gravação no servidor estão **adiados**, não proibidos. Comunidade e
monetização são objetivos futuros, preservando a originalidade.

## Motivo

O público hoje é o fundador e amigos; o app leve, sem dados guardados, é mais simples e mais
seguro até haver motivo para mudar.

Não rediscutir sem o usuário.
