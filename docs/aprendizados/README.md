# Aprendizados

Diário curto do que o processo ensinou: dificuldades, boas ideias, o que ajudou, o que poderia ser
melhor e erros que não vamos repetir. Toda área anota aqui, no mesmo PR em que aprendeu.
No fim do projeto, ou num bom momento, o usuário e o copiloto revisam a pasta e decidem o que vira
skill ou serve para projetos futuros, específicos ou gerais.

## Arquivos (um por tipo)

| Tipo           | Arquivo                                | O que entra                                        |
| -------------- | -------------------------------------- | -------------------------------------------------- |
| `dificuldade`  | [dificuldades.md](dificuldades.md)     | O que travou ou custou caro                        |
| `ideia`        | [ideias.md](ideias.md)                 | Boa ideia que surgiu no caminho                    |
| `ajudou`       | [ajudou.md](ajudou.md)                 | O que funcionou e vale repetir                     |
| `melhorar`     | [melhorar.md](melhorar.md)             | O que poderia ser melhor                           |
| `erro-evitado` | [erros-evitados.md](erros-evitados.md) | Erro que não vamos repetir, com a regra que nasceu |

## Formato da entrada

Mais nova no topo, 2–4 linhas, com link para a issue ou PR:

```
### AAAA-MM-DD · área · título curto
Texto de 2–4 linhas.
Ref: #N · Vira skill? sim | talvez | não
```

Não duplique o que já virou regra: diga qual regra nasceu (CLAUDE.md, ADR ou ficha).
