# Revisões de incidente

Depois de todo **P0** resolvido, um arquivo `AAAA-MM-DD-<tema>.md` aqui. Sem culpa: o foco é o
que deixou o erro passar (teste, regra, ferramenta), nunca quem errou. Máximo de uma tela.

```md
# <tema> (AAAA-MM-DD) · issue #N

**O que houve:** uma ou duas frases, do ponto de vista de quem usa.
**Impacto:** quem, onde (prévia/produção), por quanto tempo.
**Causa:** a causa técnica e por que nenhum teste pegou.
**Correção:** PR e versão.
**Para não repetir:** teste novo, invariante no `CLAUDE.md` ou checagem na CI (com link).
```
